# Features & UX

## Two audiences, one device

| Tab | For | Job |
|-----|-----|-----|
| **Punch** | Employees | Pick name → PIN or photo → auto in/out |
| **Board** | Everyone | See today’s punches at a glance |
| **Manage** | Admin (PIN) | People, sites, fixes, reports |

## Shipped

1. Company onboarding (any company name + first site)
2. Multi-site + assign sites per person
3. Punch site filter + GPS must match an assigned site
4. PIN **or** photo (photo evidence; no face match)
5. Employee photos on lists
6. Forgot-punch / manual correction with note
7. Reports: day / week / biweek / month / year → CSV + printable summary
8. Offline SQLite kiosk

## UX polish direction

- Warm paper + forest brand (not generic SaaS green / purple)
- Large touch targets on Punch; short copy; clear success screen
- Manage hub grouped: People & sites · Attendance · Device
- Avoid stretched chips / nested scroll flex bugs (wrapping rows)

## Next (keep simple)

- Late flag (fixed clock time)
- Inactive people toggle
- Cloud backup later — not required for single-tablet use
